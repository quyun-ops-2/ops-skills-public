# 接收方说明（可直接转发）

你拿到的是一个浏览器脚本包，用来把两件手工活自动化：

1. **批量把本地视频传到 YouTube**（自动填标题、描述、可见性、发布）
2. **在 Google Play Console 批量创建自定义商店页（CSL）**，每个视频对应一个

两段共用一个脚本，靠它的本地存储把视频链接自动接上。

> 这不是官方 API 方案。CSL 根本没有 API，而 YouTube API 对外传视频有可见性限制，
> 所以这套走的是「浏览器脚本替人在页面上操作」。详见包里的 `references/方法论.md`。

---

## 一、先自查这四项（缺一项都跑不了）

| # | 需要什么 | 怎么确认 |
|---|---|---|
| 1 | 浏览器 + **Tampermonkey** 扩展 | Chrome / Edge 应用商店搜 Tampermonkey，装好 |
| 2 | 对目标应用有 **Play Console 的 CSL 创建权限** | 能自己进去手动创建一个自定义商品详情就行 |
| 3 | 一个 **YouTube 频道**，且当前浏览器**已登录**该频道 | 打开 studio.youtube.com 能看到自己的频道 |
| 4 | Play Console 里**已有一个可复制的 CSL 模板** | 建 CSL 时能选到「复制现有商品详情」的那个模板 |

> 第 4 条很关键：脚本**不创建**文案和图片，它只是复制一个你已有的模板，
> 然后把 Preview Video 填进去。所以模板必须**先手工建好**，而且里面要带图。

另外需要一个 **Python 3**（用来改配置）。没有的话见第四节的"手改"。

## 二、安装（3 步，约 10 分钟）

### 第 1 步：把配置换成你自己的

先进 `scripts` 目录，跑一次自检，看它说哪几项还是原作者的：

```bash
python configure.py
```

会看到类似：

```
  产品名        SLOT-02
  ! 产品名还是原作者的 —— 改成你自己的
```

**换成你的：打开包根目录的 `要填的信息.txt`，把四行填上**（描述写成一个 txt，放在同目录），
然后在 `scripts` 目录跑：

```bash
python configure.py --answers ../要填的信息.txt
```

它会逐条打印"改了什么、改成什么"，改坏了自动还原。**不需要记参数、也不用处理引号。**

> 不想填表也可以直接给参数，效果一样：
>
> ```bash
> python configure.py --product "你的产品名" --title "你的视频标题" \
>     --desc-file desc.txt --template "你模板的名字"
> ```

**四项分别是什么：**

| 参数 | 填什么 | 备注 |
|---|---|---|
| `--product` | 你的产品名 | 脚本用它检查文案有没有串产品 |
| `--title` | 视频标题 | 想要的区分就加 `{name}`（会替换成文件名）；上限 100 字符 |
| `--desc-file` | 一个 txt 文件，里面是视频描述 | **每行一句，空行保留**，空行就是排版 |
| `--template` | 你 Play Console 里那个模板的名字 | **必须和屏幕上看到的文字完全一致**（大小写、空格都算） |

工具会先备份、再写、再检查语法，**改坏了会自动还原**，不会给你一个跑不起来的脚本。

> **描述文件的路径**用法：写相对路径（`../desc.txt`）或 Windows 路径（`C:\xx\desc.txt`）都行。
> 但**别用 `/tmp/xxx.txt` 这种 Git Bash 写法** —— Windows 的 Python 会把它当成当前盘的 `\tmp\x`，
> 于是报"文件不存在"。报这个错先看路径写法，不是工具的问题。

> 标题和描述是**发出去收不回**的承诺，第一次务必自己核对一遍再上传。

### 第 2 步：装进 Tampermonkey

1. 点 Tampermonkey 图标 → **添加新脚本**
2. 把 `assets/csl-helper.user.js`（第 1 步改好的那份）**全文**粘进去
3. `Ctrl + S` 保存
4. 打开 <https://studio.youtube.com/> → **右下角出现面板**就成功了

> ⚠️ **不要把它拆成两个脚本**。Tampermonkey 的存储是按脚本隔离的，
> 拆开之后 YouTube 那半边的上传记录，Play 那半边读不到，两段就串不起来了。

### 第 3 步：自检

```bash
python configure.py
```

看到 `✓ 文案相关配置看起来已经是你自己的了` 就成了。
（如果还提示模板名，那是问你确认 —— 你 Console 里真叫这个名字就忽略。）

## 三、第一次跑：两个开关先别关

面板上有个「试运行」开关，**默认开着，先别关**。

| | 试运行会做什么 |
|---|---|
| YouTube 侧 | **只处理队列里的第一条** —— 因为上传本身就真实占配额且不可撤销 |
| Play 侧 | 走完全部步骤，**最后一步不保存** —— 不保存就没有破坏性 |

### 第一段：传 YouTube

```
在 Studio 右上角「创建 → 上传视频」手动打开上传页
  → 回面板点「选择视频目录」
  → 用筛选框挑 1 条
  → 开始上传
```

★ **顺序不能反**。脚本不自己跳到上传页（每个频道的地址不一样，写死必错），
所以必须你先手动把上传页打开，再回面板点开始。反了会报"等不到 file input"。

第一条跑通、链接拿到了，再关掉试运行批量跑。

### 第二段：建 CSL

```
打开 Play Console 的自定义商品详情页面
  → 面板点「刷新视频」拉取上传记录
  → 勾选视频，确认 CSL 名称
  → 生成 CSL
```

- 它**只填 Preview Video 一个字段**，标题描述图片全随模板复制
- CSL 名称默认用文件名，可以逐条改；**创建后改不了**，只能删了重建（还占配额）
- Play 的**发布永远是人工点**，脚本到「保存」就停

#### 如果视频是用 API 在脚本外传的

这条链默认只认**它自己传的**视频记录。用 API 在外部传的那些，YouTube 上确实存在，
但面板里看不到 → 需要先补一步：

```
在 studio.youtube.com 的面板点「导入外部上传记录（JSON）」
  → 选那个 JSON（records-xxx.json 或 uploaded.json 都认）
  → 回 Play Console 刷新，就能看到了
```

导入是**合并**，不是覆盖：已有的记录一条不动，只补没有的、只填还没链接的。
日志会分开报「新增 / 补上链接 / 跳过已有」，对得上数再往下走。

## 四、常见问题

| 现象 | 原因 / 怎么办 |
|---|---|
| 面板不出现 | Tampermonkey 里脚本是否启用；刷新页面；确认在 studio.youtube.com 或 play.google.com/console |
| "等不到上传用的 file input" | 上传对话框没打开 —— 先手动打开「创建 → 上传视频」 |
| "这个模板找不到" | `--template` 的名字和 Console 里看到的不一致，逐字符对一遍 |
| "选择器还没配置" | 你的 Console 页面结构和实测的不一样，需要重新走查（见 `references/坑点与约束.md`） |
| 建出来的是草稿 | 「保存」和「保存为草稿」是并排的两个按钮，配错了 |
| 传上去的视频别人看不见 | 被锁成私享了 —— 这就是为什么不能用 API，改用这个浏览器方案 |

**没有 Python 怎么改配置**：照 `references/配置替换清单.md` 手改 4 处，
改完务必跑一次 `node --check assets/csl-helper.user.js` 确认没改坏。

## 五、三条边界（用之前请认一下）

1. **配额不可回收**。CSL 有 50 个配额上限，建一个占一个，删了也不退；
   YouTube 上传扣了也不返还。所以默认试运行、默认有上限，别一上来就放开跑全量。
2. **发布由人点**。脚本只到保存，不会自动发布、不会送审。
3. **只在自己的账号上用**，并且自行确认这样操作符合平台的条款。
   脚本不做任何绕过风控的事（不注入 token、不伪造指纹、不接管登录）。
