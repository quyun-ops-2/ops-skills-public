# 配置替换清单（手改版）

> **推荐先试 `python scripts/configure.py`** —— 它会自动备份、改完还做语法检查。
> 这份清单是给"想自己改"或"工具改不了"的情况看的。
>
> ⚠️ **行号会随脚本版本变化**，以注释里标出的**搜索关键词**为准。
> 当前对应 `csl-helper.user.js` 的 `@version 3.2.60`。

---

## 一、必须改（不改就会出事）

| # | 搜索关键词 | 行号(3.2.60) | 原值 | 改成 | 不改的后果 |
|---|---|---|---|---|---|
| 1 | `product_name:` | 499 | `'SLOT-02'` | 你的产品名 | 文案哨兵拿别人的产品名做判据 |
| 2 | `title_template:` | 531 | `'Welcome to SLOT-02 — …'` | 你的标题 | ★ **所有视频都发成别人的标题**，发出去收不回 |
| 3 | `description_template:` | 555 | 12 行数组 | 你的描述 | ★ **所有视频都带别人的描述**（含具体数字承诺） |
| 4 | `template_name:` | 788 | `'默认商品详情'` | 你 Console 里的模板名 | 找不到模板 → 报错停下（不会静默错） |
| 5 | `known_products:` | 503 | 4 个产品名 | 你的产品全集 | 禁忌名单算错，串产品了也查不出来 |

### 第 1 项：product_name

```js
product_name: 'SLOT-02',
```

**只给文案哨兵用，不参与拼装**。判据是双向的：

1. 标题里**必须出现**这个产品名
2. 全文里**不许出现** `known_products` 里**其他**的产品名

换产品时，这个字段和下面两份文案要一起改。

### 第 2 项：title_template

```js
title_template: 'Welcome to SLOT-02 — fast, intense Vegas-style slot action with no unnecessary fluff! 🎰🔥',
```

- `{name}` 会替换成文件名（去后缀）。想区分每条就加上，不想区分就一个字都别加
- **上限 100 字符，按码点算**。emoji（🎰🔥）在 JS 的 `.length` 里各占 2，
  所以别用 `slice(0,100)` 自己截 —— 会把 emoji 劈成半个，**标题回读随即对不上，
  而那一步抛错时配额已经扣了**。脚本内部走的是按码点截断的函数

### 第 3 项：description_template

**注意这是个数组 + `.join('\n')`，手改最容易在这里把脚本改坏：**

```js
description_template: [
    '第一行',
    '',
    '空字符串就是空行 —— 描述排版靠它',
    '第二段',
].join('\n'),
```

- 最后一行的 `].join('\n'),` **必须保留**，漏了就是语法错误
- 每行是单引号字符串，行内单引号要写成 `\'`，反斜杠要写 `\\`
- 数组里**不能有空行**（空行要写成 `''`）
- 不想要描述就整体改成 `description_template: '',`
- YouTube 描述上限 5000 字符

★ 描述是**对玩家的承诺**（"100+ SLOTS""2 MILLION virtual coins" 这类是具体数字），
写错收不回。改完建议打开发一条已上传的视频，肉眼对一遍。

### 第 4 项：template_name

```js
template_name: '默认商品详情',
```

**必须和你 Play Console 里看到的那行文字完全一致**（大小写、空格都算）。
脚本按可见文字找，找不到就报错停下 —— 不会退化成"随便选一个"。

> 这个名字是中文界面下的。如果你的 Console 是英文，可能是 `Default store listing`
> 之类，**以你屏幕上看到的为准**。

### 第 5 项：known_products

```js
known_products: [
    'SLOT-02', 'SLOT-01',
    'SLOT-04', 'SLOT-03',
],
```

把**你们做过的所有产品**列进来。它的唯一用途是算"不许出现谁"：
`禁忌名单 = 全集 − 当前产品`。

★ 为什么要算而不是写死：产品会来回切（实测两天切一次）。
写死"不许出现 X"的判据，在切到 X 的那天**它自己就变成错的**，
会红，而看的人第一反应是"代码改坏了"。

## 二、可以按需要调

| 项 | 行号 | 默认 | 说明 |
|---|---|---|---|
| `default_visibility` | 464 | `'public'` | 视频可见性。**Play CSL 只认 public / unlisted**，private 校验不过 |
| `auto_publish` | 474 | `null` | 传完是否自动点发布。`null` = 面板说了算；`false` = 硬闸，勾了也不发 |
| `max_per_run`（YouTube） | 455 | `0` | 0 = 不限。靠 `max_fail_streak` 兜底 |

| `thumbnail_index` | 628 | `0` | 从 YouTube 自动生成的截图里选第几张（0 起）。**选填，失败就跳过** |

| `audience` | 827 | `'ads'` | 受众固定走广告流量。**不要再加"受众网址"那条路**（3.2.60 已删） |

## 三、改完怎么验

**不要靠"看起来对"**。三道检查，从便宜到贵：

```bash
# ① 语法检查（3 秒，不通过就是改坏了）
node --check assets/csl-helper.user.js

# ② 读回配置（确认 5 项都变成你的了）
python scripts/configure.py

# ③ 在浏览器里跑一遍试运行（YouTube 侧只传第一条；Play 侧走到底不保存）
```

第 ② 步的正确输出应该是：

```
  产品名        MY GAME SLOTS
  标题模板      Welcome to MY GAME SLOTS — …
  CSL 模板名    你填的那个名字
  描述模板      N 行，共 N 字

  ── 判断要不要改 ──
  ✓ 看起来已经改成你自己的了。
```

---

## 四、为什么建议用工具改

`configure.py` 做的手改做不到的三件事：

1. **改前自动备份** `.bak`
2. **改后跑 `node --check`**，不过就自动还原 —— 手改坏了常常要到浏览器里才发现
3. **正确处理多行数组和转义**（`description_template` 的 `].join('\n'),` 尾巴最容易漏）

另外它会读回改后的值给你看，而不是让你相信"应该改对了"。
