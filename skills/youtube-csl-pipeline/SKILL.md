# YouTube 批量上传 + Play 自定义商店页（CSL）流水线

一套可以整套交接的浏览器自动化方案：**一个 UserScript，跑两个站点，把两段手工活变成"点一次开始"。**

```
本地 mp4 目录
   ↓  ① 在 studio.youtube.com 批量上传（自动填标题/描述/可见性/发布）
videoId + 链接
   ↓  ② 在 play.google.com/console 批量建 CSL（复制模板，只填 Preview Video）
每个视频 = 一个自定义商店页
```

---

## 这套东西能复原到什么程度（先说清）

| 项 | 复原情况 |
|---|---|
| 脚本行为、两段流程、选择器、各种回读判据 | ✅ **原样复原**，脚本本体不用改 |
| 产品名 / 视频标题 / 描述文案 | ⚠️ **必须改成你自己的**，否则会用上一家的文案发视频 |
| Play Console 里的 CSL 模板名 | ⚠️ **必须改成你账号里实际那个名字**（大小写空格都要一致） |
| 账号权限、频道、素材目录 | ⚠️ 环境相关，装完自己确认 |

所以"安装后可以直接复原"准确说是：**装好脚本 → 跑一条命令换掉 4 处配置 → 就能跑**。
配置替换有工具，不用手改（手改那个多行数组很容易把脚本改坏）。

> 脚本里默认带着上一家的文案（`SLOT-02`）。**不改就会把别人的视频发成他们的文案**，
> 而标题和描述是发出去收不回的 —— 这是这套包最需要注意的一件事。

---

## 前置条件

- 浏览器 + **Tampermonkey**（Chrome / Edge 商店都能装）
- 对目标 Play Console 有 **CSL 创建权限**（开发者账号 → 目标应用）
- 一个 YouTube 频道，且**当前浏览器已登录**该频道（脚本靠页面登录态工作，不碰账号密码）
- Play Console 里**已经存在一个可复制的 CSL 模板**（图片和文案都在模板里，脚本只填视频链接）

## 安装（三步）

### 第 1 步：确认配置，换成你自己的

```bash
cd scripts
python configure.py            # 先看当前配置是什么
```

输出会直接告诉你哪几项还是上一家的：

```
  产品名        SLOT-02
  标题模板      Welcome to SLOT-02 — …
  CSL 模板名    默认商品详情

  ── 判断要不要改 ──
  ! 产品名还是原作者的（SLOT-02）—— 改成你自己的
  · CSL 模板名仍是「默认商品详情」—— 如果你 Console 里确实叫这个名字，忽略即可
```

**换成你自己的（推荐填表）：** 打开包根目录的 `要填的信息.txt`，填四行，然后在 `scripts` 目录跑：

```bash
python configure.py --answers ../要填的信息.txt
```

不想填表也可以直接给参数，效果一样：

```bash
python configure.py \
    --product "MY GAME SLOTS" \
    --title "Welcome to MY GAME SLOTS — spin the reels and win big!" \
    --desc-file my_desc.txt \
    --template "默认商品详情" \
    --known "MY GAME SLOTS,OTHER GAME"
```

| 项 | 说明 |
|---|---|
| `--answers` | 读 `要填的信息.txt`。★ **命令行参数优先**，填空文件只补没给过的项 |
| `--product` | 产品名。视频标题**必须**包含它，且文案里**不许**出现 `--known` 里的其他产品名 |
| `--title` | 视频标题模板。`{name}` 会被替换成文件名（去后缀）；不用就写固定文案 |
| `--desc-file` | 描述 txt，**每行一句，空行保留**（YouTube 描述里的空行就是排版） |
| `--template` | Play Console 里那个模板的名字，**必须和你看到的文字完全一致** |
| `--known` | 已知产品全集，逗号分隔。**可以不给** —— 只改 `--product` 时会自动把新产品并进全集。给了就整组替换 |
| `--dry-run` | 只预览，不写文件 |

工具会：**先备份 `.bak` → 写入 → 跑 `node --check` 语法检查 → 不过就自动还原**。
所以改坏了不会留下一个跑不起来的脚本。

> 标题和描述**第一次一定要自己核一遍**。描述里的"100+ SLOTS""2 MILLION coins"
> 这类具体数字是对玩家的承诺，抄错了收不回。

### 第 2 步：装进 Tampermonkey

1. Tampermonkey 图标 → **添加新脚本**
2. 把 `assets/csl-helper.user.js`（改好的那份）**全文**粘进去
3. `Ctrl+S` 保存
4. 打开 <https://studio.youtube.com/> 或 <https://play.google.com/console/> → **右下角出现面板**

两个域名都在白名单里，别的地方不运行。白名单是硬闸门，留空会直接拒绝运行。

> ⚠️ **不要改成两个脚本**。Tampermonkey 的 `GM_setValue` 存储按脚本隔离，
> 拆开的话 YouTube 侧传完的记录 Play 侧读不到 —— 两段就串不起来了。
> 这是"一个脚本跑两个站点"的唯一理由。

### 第 3 步：自检

```bash
python configure.py            # 应该不再提示"还是原作者的"
```

然后在浏览器里打开 Studio，确认右下角面板出现、且日志里打印的版本号不是 `读不到`。

## 用法

### 第一段：批量上传 YouTube

```
在 Studio 右上角「创建 → 上传视频」手动打开上传页 → 回面板 → 选视频目录 → 勾选 → 开始上传
```

**脚本不自己导航到上传页** —— `studio.youtube.com` 的频道 id 是每个人的，写死必然错。
所以顺序不能反：先手动打开上传页，再回面板点开始。

面板四块：选目录（只读文件名和大小，不上传）／视频列表（筛选 + 全选/反选）／
可见性·自动发布·试运行／开始上传 + 日志。

筛选用法：多个词空格隔开是 **AND**；全选/反选**只作用于当前筛出来的**，
"开始上传"也只传筛出来的 —— 因为上传真实占配额且扣了不返还。

> 想先看会传什么，不开浏览器也能预演：
> `node ../tools/preview-upload-queue.js "<素材目录>"`（若随包带了 tools）

### 第二段：批量建 CSL

```
打开 Play Console 的 CSL 页面 → 面板「刷新视频」拉上传记录 → 勾视频 + 填 CSL 名称 → 生成
```

- **只填 Preview Video 一个字段**，标题/描述/图片全随模板复制 —— 少填一个字段就少一个填错的机会
- CSL 名称默认用文件名去扩展名，可逐条改；**创建后不可修改**，重名会在开跑前直接拒绝
- 模板按可见文字找，找不到就报错停下，**不会退化成随便选一个**
- 发布比例、受众群体（广告流量）都在流程里处理

#### 外部传的视频要先进来（3.2.61 起）

面板只认**它自己传的**记录。如果用 API 在脚本外批量传过（见 skill `youtube-api-upload`），
那些视频在 YouTube 上有 videoId，但面板里没有 → 建不出对应的 CSL。先补一步：

```
studio.youtube.com 面板 →「导入外部上传记录（JSON）」→ 选文件
  → 回 Play Console 刷新
```

`records-*.json`（数组）和 `uploaded.json`（字典）都认。

导入是**合并不是覆盖**：已有记录一条不动，只补没有的、只填还没链接的。
日志分开报「新增 / 补上链接 / 跳过已有 / 文件内重复」，**对得上数再往下走**。
写完会回读确认——油猴存储写失败是吞错的，不回读就只是"我说它进去了"。

### 试运行

| | Play 侧 | YouTube 侧 |
|---|---|---|
| 做什么 | 走完全部步骤，**最后一步不保存** | **只处理队列第一条** |
| 为什么不同 | 保存才有后果 | **上传本身就真实占配额且不可撤销** |

**第一次上手，两边都先开着试运行跑一遍。**

## 边界与风险（请读）

**这套方案不是"官方支持的做法"。** 它用浏览器脚本替代人在页面上点，绕开的是平台规则而不是技术难度：

- **建 CSL 没有任何 API**（`androidpublisher` v3 不含 CSL 资源）
- **YouTube API 上传对未过审项目只能传成 private**，而 CSL 的 Preview Video 只收 public/unlisted

所以用之前请自己判断：

1. **遵守平台条款**。自动化操作 Console 可能违反 ToS，风险由使用者承担。
2. **不要绕过风控**。脚本只做页面操作，不注入 token、不伪造指纹、不接管登录。
   如果被拦了，说明这个做法本身可能不合规 —— 该评估的是风险，不是加手段绕过去。
3. **配额不可回收**。CSL 有 50 个配额；YouTube 上传扣了也不返还。所以默认试运行、默认有上限。
4. **发布永远人工**。Play 侧到"保存"就停，不点发布、不送审。YouTube 侧发布受开关控制。
5. 只在自己的账号上用。

## 出问题先看这几处

| 现象 | 先查 |
|---|---|
| 面板不出现 | Tampermonkey 里脚本是否启用；当前域名是否在 `@match` 里；刷新页面 |
| "选择器还没配置" | 说明你的 Console 页面结构和原先实测的不一样，要重新走查（见 `references/坑点与约束.md` 的走查章节） |
| "等不到上传用的 file input" | 上传对话框没打开 —— 先手动打开「创建 → 上传视频」再点开始 |
| 模板找不到 | 名字必须和你 Console 里看到的那行文字**完全一致**（大小写、空格） |
| 建的 CSL 是草稿 | 「保存」和「保存为草稿」并排，配错了；见坑点文档 |
| 视频传上去看不见 | 被锁 private 了 —— 这就是为什么要用浏览器路而不是 API |
